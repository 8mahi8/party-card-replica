# ローカル試遊画面（単体HTML）

これは **基本ルールの手動検証専用** です。完成版ではありません。

- `demo/standalone.html` はインポートやネットワーク通信のない単体HTML。Google Sitesの**コード直接埋め込み**に使える構造です。
- 1台の端末でP1/P2が交代するホットシート方式。手番交代時は手札を一旦隠します。
- 攻撃、装備防御、ダメージ、反射、奇跡単体、オーラ、＋攻奇跡、祈る、通常破棄の一部を操作可能。未検証の組み合わせはエンジン側で拒否します。
- サンプルカードを使うため、**原作の出現率や353種類の全カードを再現しません**。一部の選択結果は未対応のエラーを出します。
- オンライン通信、BOT、状態異常、終末、全体攻撃、災い、守護神は未実装です。

`node demo/build.mjs` で `src/*.mjs` のモジュールをインライン化して再生成できます。外部依存なし。

正式な対戦用UIではなく、**操作するとゲームエンジンで何が起きるかを再現・検証する道具**として扱います。Google Sitesに貼り付けても、既存の学校公開ゲーム版は勝手に差し替えないでください。
