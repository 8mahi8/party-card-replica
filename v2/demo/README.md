# CARD LAB V2：学校iPadの試遊画面

**V2開発用の1台交代制（ホットシート）デモ。完成版ではありません。**

## 内容

- [単体HTML](standalone.html)：HTML、スタイル、V2戦闘エンジン、画面の動作を一つのファイルへ収録。外部サービスや音声は不要。
- [画面テンプレート](template.html) / [ビルドスクリプト](build.mjs)
- [画面コード](../lab-ui.mjs) / [ゲーム操作状態](../lab-controller.mjs)
- iPad Safari用にタップしやすいボタン、レスポンシブなカード表示、手番交代時の手札隠しを用意。
- **現時点は2人・オフライン限定。** オンラインでもBOTでもない。学校の既存Google Sitesページは変更していない。

## 遊び方

1. 手番の人に端末を渡し「自分の手札を見る」を押す。
2. 攻撃先、使うカード、習得済み奇跡を選ぶ。タップした順序がカード選択の順番。再タップで解除。
3. 「攻撃を確定」を押す。未対応の組み合わせ・MP不足の攻撃は相手の防御画面へ進む前に拒否され、カードを選び直せる。
4. 端末をもう一方のプレイヤーに渡す。手札が伏せられるので「自分の手札を見る」を押し、必要なら防具や壁などを選んで「防御を確定」。無選択なら無防御。
5. 反射、弾く、次のターン、勝者判定はV2エンジンが処理する。
6. 「最初からやり直す」は2回押すと初期化される。

## 重要な制限

- 開始手札は**テスト用に固定した9枚ずつ**。現在研究済みの部分カード台帳に存在するカードのみで構成。
- 消費したカードの補充は、固定のカード「革の帽子」を使う**試験用の仮実装**。原作の出現率を再現しない。
- 特殊効果は原作の一部のみ。未確認の組み合わせは拒否する。3〜9人対応も画面上はまだない。
- 対戦履歴、録画、リプレイ、ログ、通信は保存しない。
- 手札隠しは同一端末で交代するための表示上の工夫であり、オンライン対戦の真正な秘密保護ではない。
- 学校iPad実機での画面の見え方、Google Sites埋め込み枠との相性は**未検証**。

## 開発者用コマンド

外部npm依存なし、Node.js 20以上。

- 生成：node v2/demo/build.mjs
- 単体HTMLとソースの一致チェック：node v2/demo/build.mjs --check
- テスト：npm test

ビルドは指定された14モジュールだけを扱い、それぞれをクロージャで隔離しながら結合する。未知のimport/export記述は拒否する。出力は単体HTMLなので、学校用のGoogle Sites「コードの埋め込み」で利用できる構造を保つ。ただし**現段階では学校公開版を差し替えないこと**。

参考：[Google Sites公式ヘルプ](https://support.google.com/sites/answer/90569?hl=ja)、[Pointer Events仕様](https://www.w3.org/TR/pointerevents/)。
