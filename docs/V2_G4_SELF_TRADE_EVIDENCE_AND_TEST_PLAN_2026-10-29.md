# G4｜「自分に売る」の一次寄り証言と未確定決済（2026-10-29）

対象：開発用 V2 オフライン研究ラボ。学校公開版・main へは変更しない。

## 1. 原作証拠（証拠レベルを分離）

1. **2024-07-18、経験者本人の操作解説**：[廻炎とーま『ゴッドフィールド初～中級者向け記事』](https://note.com/tohma_kaimera/n/ndb5619ce0748) は、正体が隠れた神器を **自分宛てに「売る」** と一瞬手元を離れてから戻り、隠された正体を確認できる、と具体的に説明している。通常の他人向け押し売りとは用途が違う。作者のプレイ経験に基づく記述だが、2026年現行ブラウザのネットワーク記録ではない。
2. **2023年のプレイヤーQ&A**：[Yahoo!知恵袋](https://detail.chiebukuro.yahoo.co.jp/qa/question_detail/q14275381654) に自己指定の操作報告がある（前担当の調査）。今回、本文をウェブ取得できなかったため回答の詳細は再検証済みと扱わない。
3. **一般的な「売る」の仕組み**：[アニヲタWiki](https://w.atwiki.jp/aniwotawiki/pages/47010.html)、[実戦攻略](https://ameblo.jp/shibransk/entry-12647363984.html) に、他人への売却は価格に従う金→MP→HPの精算、取引を受けるとHP0にもなる事例がある。ただし**これを自己指定にそのまま当てはめる根拠はない**。

**判定**：少なくとも過去の原作に「自分に売る」選択と、商品が自分に戻る操作の強い証言がある。現行の自己指定可否、価格精算、鏡応答、手番、ドロー、カードの正体解除は**別々の未解決事項**。推測で通常の `uncontestedSale` と同一扱いにしない。

## 2. V2 の現状と相違

- `v2/staging-room.mjs` `declareSale` は自己 `targetId` を拒否。
- `v2/trade-sale.mjs` と `v2/trade-reflection.mjs` のpreviewも自己宛を拒否。
- `v2/lab-controller.mjs`／`v2/lab-ui.mjs` はオフライン取引UIで自己取引を研究未確認として明示制限。
- これは **LAB-ONLY fail-closed**。原作も自己売却不可、と誤って主張しない。
- 「売る」を別の「売る」で売却すること、および18枚手札への売却は別の根拠で研究実装済み。今回の自己指定と混同しない。

## 3. 現行原作で確認すべき具体的トレース

**実験前**：プレイヤーAのHP/MP/¥、手札順、使用用の「売る」と別個体の商品、習得済み奇跡、手番を記録。可能なら2人のブラウザ画面を同時録画し、公開／非公開情報を分ける。既存カード価格の異なる組合せを用いる。

| ケース | 記録する事実 | 関連する未解決点 |
|---|---|---|
| Aが自分を指名、価格0の商品 | 自己指名UIの可否、商品移動、使用「売る」の補充、ターン、商品所有権 | selfTarget, handTransfer |
| Aが自分を指名、価格5の商品 | Aの¥/MP/HP、売却益表示、カード順、ドロー | selfPayment, selfCredit |
| Aが自分を指名、正体の隠れた商品 | 正体が実際に見えるか、戻る時の個体・スロット、隠蔽フラグ | revealState |
| Aの手札が18枚の時に自己売却 | 自己移動が上限抽選を発生させるか | handOverflow |
| AとB双方にミラーがある通常売却 | 応答権の回数、次の対象、カード消費・補充の時刻 | mirrorChain |
| 相手BがHP1/MP0/¥0で高額売却 | 昇天・売り手への最終入金・受渡し・勝敗決定順 | lethalCredit |

以上は**実験計画であり、確認済みの結果ではない**。現行原作の実操作または同等に強い証拠を得るまでは、不明分岐のエンジンを実装しない。

## 4. 将来実装時の最小契約

- `selfTarget` を通常の2人間 `tradeDefense` と機械的に同一扱いしない。通常売却の `buyer!==seller` という前提が破れるため、公開表示、手番、受け手、カード移動／支払いイベントを独立に監査する。
- 既存の `commandId`・`expectedRevision`・`authorizedSeatId`・個体ID・共有効果キューを維持する。
- 確定したケースを先に純粋プレビュー＋golden testにする。原作の不明挙動は明示エラー（研究用制限）を維持する。
- G6オンライン接続、G7全353種/500参照枠、学校Google Sitesへの反映はこの調査では実施しない。

## 5. 優先順位

**P0：現行自己売却のUIと最終的なカード移動の直接証拠**。次に価格5円での精算とドロー。さらに複数ミラーとHP0売却の実戦トレースを確保する。自己売却が現行で廃止されている可能性も残す。
