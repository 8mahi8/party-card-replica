# 開発ロードマップ — 原作との差分を減らす順番

## 今後の作業

1. **参照バージョンの固定**：原作の現行仕様と第三者Wikiの記述差を整理。未確定事項をリスト化する。
2. **カードデータ整備**：カテゴリ、属性、重み、基本数値、例外効果を整理し、総重み500・種類数353を検証する監査器は`src/catalog-audit.mjs`に実装済み。**カード35種類だけ部分的に登録済み（残り318種類の調査が必要）**。未確認値を埋めない。2024年と2025年の資料で分類値が異なるため、`docs/SCOPE_AND_SOURCES_2026-10-26.md`を参照してから採用する。
3. **カード部分データの監査**：`src/verified-basic-cards.mjs`に35種類の基本武器/防具を保存。`src/catalog-audit.mjs`の`createAuditedDraw`は353種類・500枠の揃わないデータでは抽選器の作成を拒否する。照合結果は`docs/CARD_RESEARCH_2026-10-26.md`。
4. **決定的な戦闘ステートマシン**：`src/match.mjs`に基本形（攻撃→防御→状態更新→補充→ターン交代、任意の乱数注入）を実装済み。特殊反応・奇跡・全体攻撃は未実装。
5. **原作ケースとの比較**：反射、範囲攻撃、光/闇、奇跡、売買、災い、守護神など例外を順次検証する。
6. **BOTとローカル対戦**：iPad横向け画面。表示素材・文章は独自制作し、ゲーム進行は調査できる限り原作準拠とする。
7. **無料オンライン同期**：部屋番号で1vs1、必要なら人数を増やす。ホスト/ゲストが同じ結果に収束する方式にする。学校iPadで匿名認証が使えないケースも考慮。
8. **Google Sites版**：HTML/CSS/JavaScriptを**コードとして直接貼り付ける**単体HTMLを用意する。GitHub Pages URLの埋め込み方式とは区別。
9. **実機品質確認**：本家と異なる挙動が残る限り「完全再現済み」と表示しない。独自のバランス調整はしない。
