# 開発ロードマップ — 原作との差分を減らす順番

## 今後の作業

1. **参照バージョンの固定**：原作の現行仕様と第三者Wikiの記述差を整理。未確定事項をリスト化する。
2. **カードデータ整備**：カテゴリ、属性、重み、基本数値、例外効果を整理し、総重み500・種類数353を自動検証する。未確認値を埋めない。
3. **決定的な戦闘ステートマシン**：選択→攻撃→防御→特殊反応→状態更新→補充→ターン交代。テスト用に乱数を外から注入可能にする。
4. **原作ケースとの比較**：反射、範囲攻撃、光/闇、奇跡、売買、災い、守護神など例外を順次検証する。
5. **BOTとローカル対戦**：iPad横向け画面。表示素材・文章は独自制作し、ゲーム進行は調査できる限り原作準拠とする。
6. **無料オンライン同期**：部屋番号で1vs1、必要なら人数を増やす。ホスト/ゲストが同じ結果に収束する方式にする。学校iPadで匿名認証が使えないケースも考慮。
7. **Google Sites版**：HTML/CSS/JavaScriptを**コードとして直接貼り付ける**単体HTMLを用意する。GitHub Pages URLの埋め込み方式とは区別。
8. **実機品質確認**：本家と異なる挙動が残る限り「完全再現済み」と表示しない。独自のバランス調整はしない。

## 現在の受け入れ条件

- `npm test` の基礎10件が通ること。
- カードや処理について「確定／資料からの推定／未調査」を区別すること。
- 原作の画像・ロゴ・説明文を含めないこと。
- 学校で稼働している他ゲームのリポジトリやGoogle Sites版を勝手に書き換えないこと。
