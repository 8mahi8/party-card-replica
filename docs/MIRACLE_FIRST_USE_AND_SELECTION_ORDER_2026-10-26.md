# 奇跡の初回使用・選択順調査（2026-10-26）

## 結論（原作資料の照合）

1. **初回使用**：手札から奇跡を唱えると、そのカードは「習得済み」欄へ移り、奇跡使用による1枚ドローで手札の枠が補充される。手札枚数は原則増えない。**2回目以降**は習得済みから唱えるため、手札が1枚純増する。
2. **先頭の奇跡と途中の＋攻奇跡は違う**：攻撃で最初に選んだ〈火の玉〉・〈流星〉は単体の奇跡攻撃扱い。武器のあとに追加した＋攻奇跡は武器攻撃の数値・属性を変える。
3. **選択順に制約がある**：原作BOTのサーバー操作検証には「流星→火の玉」は不許可、一方で「パンチ→火の玉→火の玉」は許される例がある。複数選択を無条件に許す実装は原作再現ではない。
4. **精霊系の割引は直前の奇跡1回のみ**：複数の奇跡の後に精霊を置いた場合でも前の全部を無料にするのは誤り。今回精霊自体は未実装。

## 調査出典

- [2015年：ゴッドフィールド タイマン考察・手札を増やす](https://ameblo.jp/godfield-tactics/entry-12099641663.html)：一度使った奇跡は消えず、**2回目以降**の発動で手札が1枚ずつ増える旨。
- [ゴッドフィールドWiki 奇跡一覧](https://w.atwiki.jp/piong/pages/20.html)：初使用時の習得、6個上限、使用時の1枚補充、精霊系神器の割引対象は直前に選択された奇跡。
- [2025年 God Field超分析・Bot作成編2](https://note.com/oreapo_note/n/n7791e8e30943)：サーバーが選択順を検査。＋攻奇跡の先頭選択と、武器の後に使う＋攻の扱い、〈火の玉〉を2回つなぐ合法例、精霊の割引順。
- [God Field ルールWiki](https://w.atwiki.jp/piong/pages/16.html)：習得済み奇跡の再使用、祈る、手札上限。

**注意**：これらは第三者が記録した仕様で、2026年10月の原作サーバーで同一挙動を独立に観測したものではない。上記の「初回は1枚置換」という内部表現は、複数資料の挙動からの再現仮説。原作と突合する必要がある。

## 今回の修正・実装

- `src/match.mjs`：`playMiracleAttack`（単体奇跡）、`defend` の〈壁〉、`playAuraWeaponAttack` の初回使用時にカードを手札から取り除き、習得済みへ移す。既存の「奇跡使用1回につき1枚補充」処理を維持。
- `src/plus-miracle.mjs`：`playPlusMiracleAttack` の同様の処理を修正。`playStackedPlusMiracles` を追加。**通常武器／追加武器から始まり、手札にある＋攻奇跡2枚が続く**限定パターンにだけ対応。攻撃加算、属性合成、合算MP消費、初習得、各奇跡の補充を処理。
- 既存の〈オーラ〉〈壁〉〈火の玉〉〈氷〉等のテスト期待値を訂正。反射後の手札インデックスも更新。
- `tests/miracle-first-use-and-stack.test.mjs` 6件を追加。初回・再使用を繰り返して手札増分を比較、壁・オーラ・火の玉、2枚連結、違法順序、MP不足を確認。
