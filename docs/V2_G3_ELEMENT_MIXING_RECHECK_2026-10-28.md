# V2 G3｜属性を合わせると無属性になる？原作資料の再調査（2026-10-28）

## ユーザー指摘と調査結果

ユーザーから「属性は合わせたら無属性になるはず。調べてみて」と指摘。実装を修正する前にゲーム仕様と教典への言及を調べ直した。

確認した資料：
1. https://w.atwiki.jp/piong/pages/16.html 「属性攻撃の足し算」: **異なる属性の神器を複数使用すると無属性**。光は火・水・木・土と合わせるとその属性になる例外。さらに「○属性に染める」は無条件でその属性に変更できる特殊武器と明記。
2. https://kankurou53.hatenablog.com/entry/2025/07/19/165703 : 公式のゲーム内「教典」の説明として異なる属性を混ぜると無属性と引用。**神の剣＋エンゼルの弓＋発火のワンド＝火47**という、普通の混合を覆す実戦例あり。
3. https://ameblo.jp/rinnka-111/entry-11631499310.html : 「無＋属性＝無」「違う属性＋違う属性＝無」「同じ属性＋同じ属性＝属性」を明記。旧版の情報であるため、同属性の持続は他の資料も参照する。
4. https://w.atwiki.jp/piong/pages/15.html : 魔水のワンド＝水＋攻5／水属性化、発火のワンド＝火＋攻2／火属性化。
5. https://w.atwiki.jp/gfplusa/pages/19.html : オーラの倍化は基本的に追加武器が後にあっても適用、ワンダーソード→オーラ→魔水のワンドの実例。
6. 2025年の上記記事の**脚注*8**は、仕様が変更され「オーラの後にワンドを使わないといけなくなった」と記載。2024年のオーラ順序の説明と、**攻撃値の倍化／ワンドの属性着色の順序**を混同しない。

これらは攻略Wiki・プレイヤーの記事であり、**AI自身が本家修行モードで直接操作して得た結果ではない**。同一属性同士、ワンドをオーラより先に使った場合、両方の色付けワンドを使った場合は、ゲームのバージョン差や実機での検証余地がある。

## 現在サポートする属性合成

| 組み合わせ | 通常の結果 | 根拠 |
|---|---|---|
| 無＋火 | 無 | 違う属性を混ぜる通常則 |
| 火＋水、火＋木 | 無 | 違う属性の通常則 |
| 火＋火 | 火 | 同属性の持続、旧ゲームプレイ解説 |
| 光＋火 | 火 | 光例外 |
| 光＋水 | 水 | 光例外 |
| 光＋木 | 木 | 光例外 |
| 光＋土 | 土 | 光例外 |
| 別属性武器＋魔水のワンド | 水 | 属性変更特殊効果 |
| 別属性武器＋発火のワンド | 火 | 属性変更特殊効果 |

通常則と例外を混ぜない：**「どの属性を合わせても必ず無属性」は誤り**。反対に、染色用ワンドが単なる属性つき＋武器という扱いも誤り。

## コード監査と修正

- `src/rules.mjs`の既存`combineElements`は「同一属性は維持、異なる属性は無（ただし光＋四属性は四属性）」をすでに実装していた。**一般の合成規則は変更不要**。
- `v2/ordered-attack.mjs`にあった「ワンドの色と異なる属性の武器が混ざると拒否する」条件は、ゲーム仕様の「染める」効果と矛盾する**不必要な制限**だったので解除。効果タグ`setAttackElement`で最終属性を染色する。
- `tests/attribute-wands-aura-v2.test.mjs`を修正し、火の武器＋魔水のワンド→水属性、つらら＋発火のワンド→火属性、無武器＋無追加武器＋発火のワンド→火属性を戦闘の実ダメージまで回帰確認。
- `tests/element-mixing-g3-v2.test.mjs`新設。属性の直接組み合わせ15例、実際の攻撃カード7例、防具との属性相性を追加検証。
- **オーラの後にワンド**の資料はあるものの、逆順でワンドの属性が発動するかは2025年の「仕様変更」記載により確認が必要。従来の`ワンド→オーラ`で**水属性を無条件に与える実装は撤回**。検証版は順序に矛盾がある選択を原子的に保留し、正解として別の属性を捏造しない。
- 2枚の染色ワンド、ワンド＋火の玉/流星、オーラ＋火の玉は、まだ最新本家の順序・合成結果を直接検証できていないため、引き続き研究用UIでは未対応。
