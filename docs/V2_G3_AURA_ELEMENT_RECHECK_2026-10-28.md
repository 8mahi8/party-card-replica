# G3｜オーラの属性再照合・修正（2026-10-28）

## 調査結果

「ちからの粉→オーラ」の攻撃数値を引き続き調べたが、原作の具体的なダメージ記録（例：パンチ3＋粉10＋オーラの最終攻撃値）を確認できなかった。**本家の合法なカード選択**（「パンチ→力の粉→オーラ→精霊」）と、**未確認のダメージ計算**を混同しない。

一方で、オーラによる攻撃の**属性**について新たに根拠のある既存実装の不一致を発見した。

1. [ゴッドフィールド攻略記事（2021年）](https://ameblo.jp/shibransk/entry-12647363984.html)：オーラ攻撃は原則無属性になると具体的に記載。
2. [God Fieldガイド＋α 奇跡一覧](https://w.atwiki.jp/gfplusa/pages/19.html)：オーラの効果は選択の前後を問わず武器に掛かる。「ワンダーソード→オーラ→魔水のワンド」の＋攻5が2倍と実例で説明。
3. [現行の神器一覧](https://w.atwiki.jp/piong/pages/15.html)：発火のワンド／魔水のワンドには「攻撃が火／水属性になる」という**属性強制変換**が明記。
4. [2025年10月の原作APIで組合せを調べたBOT研究](https://note.com/oreapo_note/n/n7791e8e30943)：粉単独は先頭不可、パンチ→粉→オーラ→精霊は組合せ可能。しかし計算の最終攻撃値は記事にない。

**エンジン変更**
- `v2/ordered-attack.mjs`：`attackElement` が元の武器の火／水／木／土／光／闇を保持したままオーラを処理していた。**通常のオーラ付き攻撃では無属性**となるよう変更。
- **例外は発火・魔水のワンドの明示的な`setAttackElement`**。オーラより後にワンドを選ぶ既存の確認済み組合せでは、最終攻撃の火／水属性を維持。
- **ワンド→オーラの逆順**は属性の優先順位が未確定なので、従来どおりエラーとして保持。
- 「ちからの粉＋オーラ」は**ダメージ計算未確認のため引き続き実行しない**。サーバーで違法と主張しているわけではない。
- 原作にはバージョン差の可能性がある。現行本家の直接操作・動画はまだ追加の確証なし。

**新規回帰テスト（`tests/aura-element-neutral-v2.test.mjs` 6件）**
- 火属性のたいまつ＋オーラ：無属性に変わり、フレイムブーツでも防御可能。
- 水属性のつらら＋オーラ：無属性になり、アイスブーツでも防御可能。
- 光属性のスタースタッフ＋オーラ：無属性になり、無属性防具で防御可能。
- 闇属性のちくりんちょ＋オーラ：無属性になるため、**闇属性の即死を誤って発動させない**。
- たいまつ＋オーラ＋魔水のワンド：最後の属性変換で水属性を保持。
- 魔水のワンド→オーラ：不明な優先順位として拒否、部屋状態不変。
