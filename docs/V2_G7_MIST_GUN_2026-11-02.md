# G7｜霧鉄砲：命中後の霧を既存エンジンで処理（2026-11-02）

## 原作資料と確度
- [Piong 単体武器一覧（2026-03-18）](https://w.atwiki.jp/piong/pages/15.html)：霧鉄砲は**水属性・攻撃3・売値¥10・取得率0.2%**。1以上の実ダメージが通った対象に「霧」付与。
- [まかろん神器一覧（2026-02-28）](https://macarongamemo.com/entry/godfield-artifact)：同じ数値と効果。
- [Piong 災い一覧（2026-09-05）](https://w.atwiki.jp/piong/pages/23.html)：霧の相手HP/MP/¥秘匿、スマイル／ハートの貝がら・音色／歌声による解除。
- [Piong 基本ルール](https://w.atwiki.jp/piong/pages/16.html)：**水攻撃を防げるのは火または光属性の防具**。水防具で水を防げるという誤ったテスト案を撤回。
- いずれも外部公開資料に基づく。原作2026年版で今回の全分岐を直接操作した一次検証ではない。

## 開発実装
- `src/verified-basic-cards.mjs`：`w061`霧鉄砲、`main(...,{element:'water',afflictionOnHit:'mist'})`、参考1/500枠。
- `v2/legacy-adapter.mjs`・`v2/foundation.mjs`：既存の型付き`afterHit:inflictAffliction`を flash/mist 共用。未研究の夢・暗雲を汎用許可しない。
- `v2/ordered-attack.mjs`→`v2/basic-resolution.mjs`→`v2/effect-runner.mjs`：既存の1回限りの命中後キューで、**0ダメージなら付与なし、実ダメージ後の生存者だけ霧付与、鏡反射で最終被弾者へ付与**。元カードと本物の攻撃文脈を検査。複数武器や未調査連携は従来どおり拒否。
- `v2/staging-room.mjs`の霧の席別非公開ステータス投影、`v2/disease-rules.mjs`の軽症・全治療は**変更せず再利用**。霧を持つ本人だけ相手HP/MP/¥が見えず、ホスト内部計算は真値を使う。
- 3席以上の霧付与は原作の対象指定ルールの未検証箇所があるため研究版では拒否。
- `v2/demo/firebase-online-lab.html`に`mistGun`研究プリセット（A：霧鉄砲／B：治療用貝がら・火属性防具・鏡）。**正規山札ではない**。単体HTML3本を開発ブランチで同期。
- 部分研究台帳 **185種類／446参考枠、complete:false**。参照版の353種類／500枠は未達、別版の総数についても出典差が残る。正規山札抽選は禁止。
