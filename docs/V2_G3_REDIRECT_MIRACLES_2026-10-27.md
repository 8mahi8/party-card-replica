## 仕様・データの根拠

- [ゴッドフィールドWiki・単体武器](https://w.atwiki.jp/piong/pages/15.html)：反射剣は無属性武器攻撃をはね返し、乱弾武剣は弾く。
- [初心者ルール解説](https://godfield-beginner.game-info.wiki/)：「はね返す」は直前の攻撃元へ、「弾く」は自分を含むプレイヤーへランダム。
- [ゴッドフィールドの攻撃解説](https://idea427.hatenablog.com/entry/2023/07/31/192159)：弾いた攻撃は自分が新しい攻撃元になる。自分に弾き戻った際は防御できない。
- [ゴッドフィールドWiki・奇跡](https://w.atwiki.jp/piong/pages/20.html)：奇跡の基本値、MP消費、習得上限6。
- [ゴッドフィールドWiki・防具](https://w.atwiki.jp/piong/pages/17.html)：エンゼル防具は奇跡を止める。
- [研究済み精霊資料](SPIRIT_SEQUENCE_2026-10-27.md) は main に存在する別記録（本ブランチから参照可能）。

2026年10月の原作内部コード・サーバーを検証したのではない。カード値は登録済み68種の**部分研究データ**。

## 共通実行器 v2/effect-runner.mjs

コンパイル済みキューの標準命令：

| 命令 | 内容 |
| --- | --- |
| `spend` | cardInstanceIdで使用カードを消費し、補充必要枚数を記録 |
| `mp` | MP支払い（不足・負数は拒否） |
| `learn` | 奇跡定義IDを習得、最大6個をFIFO管理 |
| `hit` | 防御後のHP・闇即死・停止結果を反映 |
| `refill` | 生存者へ使用枚数分を補充、上限18、各cardInstanceIdを一意発行 |
| `advance` | 勝者決定または次の生存者へターン移動 |

実行前にコンパイラが合法手を確認する。命令実行器は元の状態を変更しないコピーを使用し、入力が無効なら結果を返さない。**ルームのサーバー側原子トランザクションを実装したわけではない。**

## 反射・弾くの割り込み

`resolveRedirectFixture`：防御時の反射ハンドラ。資料確認済みの次の効果のみを許可。

- 反射剣：無属性の武器攻撃を現在の攻撃元に返す。
- 乱弾武剣：無属性の武器攻撃を生存者全員からランダムに弾く（本人も候補）。値は状態内の固定seedから取得。
- スーパーミラー：属性付きも含めた**武器攻撃**を反射する。奇跡反射は未対応として拒否。
- 反射には防御カード1枚だけを許可。反射時に攻撃元と対象、使ったカードを保存し、別の防御者へ操作を委譲。
- 自分へ弾き戻った場合はその場で防御なしのダメージを確定。
- 元の手番所有者は維持し、最後の着弾後にすべての生存参加者の使用枚数を補充。

`sourceId`（現在の攻撃元）・`originalAttackerId`（元の手番の所有者）を区別。反射カードでさらに反射でき、JSON保存後も同じ順序で再開できる。

## 奇跡の最初の一歩

`resolveSoloMiracleFixture` は**手札からの初回単体攻撃奇跡**のみ。

- 〈氷〉〈闇〉〈火の玉〉〈流星〉の単独発動、MP消費・初回習得・使用枚数補充。
- 精霊のぬいぐるみを奇跡の直後に1枚置いた時のMP無料。
- エンゼル防具1枚による奇跡停止、虹のカーテンを先頭に使った防御、属性防具のガード。
- 自分を対象にする奇跡攻撃にも対応。
- 未確認の複合奇跡／反射がある場合は**明示的にエラー**。知らない効果を黙って通さない。

習得済みからの再使用は、G2の新しいコマンド型（手札インスタンスがないカードの選択）が必要なので**まだ未実装**。〈壁〉・〈オーラ〉・追加奇跡連結なども移行前。
