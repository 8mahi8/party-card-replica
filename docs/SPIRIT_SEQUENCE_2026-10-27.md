## 実装内容

1. `src/spirit-sequence.mjs` の `priceMiracleSequence` は **入力された選択順** をそのまま計算し、`miracle -> spirit` の直結だけを許可。精霊が作用するのは直前1回のみ。
2. 部分カード登録 `i003` 精霊のぬいぐるみ（価格5、重み2枠、`support_item`）。部分台帳は **68種類・186枠／500枠**。全種類が揃っていないため、現時点で本番用抽選に使えない。
3. `playMiracleAttack` の `spiritHandIndex` で、手札にある奇跡か習得済み奇跡に**直後の精霊**を付けて唱える。MPが0でも唱えられる。奇跡の習得・カード消費・補充・勝敗は従来の戦闘エンジンを利用。
4. `playStackedPlusMiracles` の `spiritHandIndex` は「武器→＋攻奇跡→＋攻奇跡→精霊」という**資料上の順序を固定**。最後の奇跡だけMP無料、最初の奇跡は通常どおり消費。精霊も1枚消費し、使用分を補充する。
5. `tests/spirit-sequence.test.mjs` 12件：直前1回のみの割引、選択順違反、MP0での発動、習得済み奇跡、2連結時の差、消費枚数と補充、部分カード台帳の防護、不正操作の非破壊性を確認。
