# ゴッドフィールドG6｜原作ブラウザ版を参照したオンラインUI改善（2026-10-30）

## 参照した原作情報

- [ゴッドフィールド初心者向け説明（ブラウザ版の画面）](https://godfield-beginner.game-info.wiki/)：プレイヤー名・HP/MP/所持金、手札「神器」、選択中の神器を表示する領域、操作方法。原作の画面全体は水色から薄緑系、下端に神器が小さく横並びになっている。
- [ゴッドフィールドwiki・ゲームの仕様](https://w.atwiki.jp/piong/pages/16.html)：攻撃は神器をタップして対象選択後に確定、防御は使える防具をタップして確定。防具を使わないときは「許す」。スマホ等では画面構成が異なる場合がある。
- [原作対戦スクリーンショット入り記事](https://note.com/moe_axera/n/n77ed29fe154d)：背景、プレイヤー名の楕円表示、中央の戦闘演出と操作エリア、下段に並ぶカード・攻撃/防御を参照した。

**方針**：原作の**画面構成と情報の優先順位**を近づける。原作のカード画像を転載・使用せず、試作中はカード分類ごとに異なる色・記号の仮表示を使う。未実装の攻撃・防御プレビューや場のカード画像を「原作と同じ動作」と見せかけない。

## 今回の実装

ファイル：`v2/demo/firebase-online-lab.html`。新しい静的配布物 `v2/demo/firebase-online-standalone.html` は同じビルダーから生成。

- 濃紺の管理画面型UIをやめ、淡いアクア・ターコイズ系のゲーム盤面へ。上部に深緑のタイトル帯、下にルーム番号/接続状態。
- 対戦中はプレイヤー2人の名前、HP、MP、お金、手札枚数を横並びパネルにまとめ、行動者を枠で強調。
- 盤面中央を「選択中の神器」と「攻撃/防御の状態」の2領域に分ける。カードをタップすると選択神器名が即時反映される。
- 手札は**縦に大きい2列ボタンではなく下部の横1列・横スクロール**へ変更。カテゴリごとに仮アート・色を区別し、攻撃、守備、MP、価格をカード上に表示。複数選択と選択順は元の仕組みを維持し、再描画時には手札スクロール位置を保持。
- 防具を未選択の場合は「許す（防御なし）」、防具を選択したら「防御する」と表示。相手のターン中の待機文言も整理。
- 390×430程度の埋込幅を考慮したCSS。`aria-label`、`aria-pressed`を維持し、iPadのタッチ操作を優先。
- 通信、Firebase、効果解決、カードデータ、固定補充、原作固有ルールは変更しない。通知欠落時の「同じ操作を再送」もそのまま残す。

## 検証と未完

- `tests/firebase-online-lab-page-v2.test.mjs`：原作に寄せた構成と下部横並び、ステータス、選択領域、`許す`表示が存在することを静的検証。
- `tests/v2-firebase-online-webkit.browser.mjs`：生成した単体HTMLの実WebKitタップ操作に加え、中央に選択神器名が出ること、選択ハイライト、HP表示、手札が横並びスクロール、未選択の防御が「許す」になることを検証。既存の再送復旧や無効カード選択からの復帰も維持。
- **最終CI実測**：UIを含む検証commit `59b94837fd0be1ad9b53384c9d78663a88c1ce9d`にて、Node **904/904 PASS**（run `40941029006`）、Chromium **28/28 PASS**（run `40941028870`）、Playwright WebKit旧UI **339/339 PASS**＋今回の原作風オンラインUIでの2画面操作 **19/19 PASS**（run `40941028890`）。途中、旧「防御待ちP2」の文言に依存したWebKit試験がタイムアウトしたため、「あなたの防御」など新UIの文言に合わせて試験を修正した。戦闘コード・対戦ルールの修正ではない。
- **配布用単体HTML**：GitHub Actionsが開発ブランチに自動再生成・保存した`v2/demo/firebase-online-standalone.html`（生成commit `1e76e8f278887b85416aaeb1573c841579e63407`）。同じUIを含む[CI ZIP artifact](https://github.com/8mahi8/party-card-replica/actions/runs/40941028890/artifacts/12925774641)も保存。スクリーンショットは同runの`v2-webkit-touch-evidence`に保存（AIによる画像自体の目視チェックは未実施）。
- 実機iPad Safari、友達の実プレイによる読みやすさ、AIによるスクリーンショット画像の目視レビューは未検証。カード個別アート、より忠実な中央の攻撃・防御表示、原作の9枚手札、正規抽選は別工程。研究版の4枚固定デッキを原作相当とは扱わない。
