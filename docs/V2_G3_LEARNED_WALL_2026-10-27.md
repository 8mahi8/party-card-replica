# V2 G3：習得済み奇跡の再使用と「壁」停止処理（2026-10-27）

## 今回完了した範囲

**既存のV2 G3基礎に、習得済みの単独攻撃奇跡と奇跡〈壁〉の防御処理を追加。** 既存main/学校Google Sites版は変更なし。

- `v2/staging-room.mjs`：新コマンド `castLearned` と `defend.learnedDefinitionId` に対応。手札のcardInstanceIdと、手札には実物がない習得済みの奇跡IDを分離。
- `v2/miracle-resolution.mjs`：習得済み〈氷〉〈闇〉などの単独攻撃、MP支払い、**手札を消費せず1枚引く**処理、上限18枚。未習得やMP不足は状態を変更せず拒否。
- `v2/effect-runner.mjs`：共通の `grantDraw` 命令を追加。手札から初めて使う奇跡は従来どおり消費カードが補充され、習得済みからの再使用はこの命令で手札が純増する。
- `v2/wall-resolution.mjs`：防御奇跡〈壁〉を専用コンパイラへ分離し、〈壁〉を手札から初使用→習得する場合と、習得済みから使う場合を区別。無属性の**非奇跡武器攻撃**のみ停止し、ダメージ0にする。〈虹のカーテン〉を先頭に選んだ場合は属性攻撃も停止可能。
- `v2/redirect-resolution.mjs`：反射/弾くがない防御選択で〈壁〉を使ったとき、専用の停止コンパイラへ転送。
- `v2/basic-resolution.mjs`：習得済み防御奇跡の指定を無視して通常ダメージとして処理しない（未対応の場合は拒否）。

## 原作資料の照合

1. [God Fieldガイド＋α 奇跡一覧](https://w.atwiki.jp/gfplusa/pages/19.html) — 一度使うと習得し、MPを払えば何度でも再使用。習得上限6。〈壁〉は「奇跡以外の無属性攻撃全て」を停止。
2. [ゴッドフィールドwiki 仕様](https://w.atwiki.jp/piong/pages/16.html) — 習得済みの奇跡を手札とは別に選択でき、手札上限18でも使用可能。
3. [ゴッドフィールドwiki タイマン攻略](https://w.atwiki.jp/piong/pages/21.html) — 虹のカーテンで属性を解除した後の停止。
4. [2026年公開の神器一覧](https://macarongamemo.com/entry/godfield-artifact) — 〈壁〉MP6、出現率0.2%。

第三者資料による研究・旧エンジンとの回帰比較であり、現行原作サーバーの内部ロジックとの一致を証明するものではない。

## 操作状態の注意点

```js
// 攻撃側：習得済み奇跡を指定。cardInstanceIdは存在しない
{type:'castLearned',actorId:'A',commandId:'cast-1',
 expectedRevision:8,targetId:'B',learnedDefinitionId:'m002'}

// 防御側：手札の虹のカーテンの後に習得済み「壁」を使用
{type:'defend',actorId:'B',commandId:'wall-1',expectedRevision:9,
 orderedInstanceIds:['ci-93'],learnedDefinitionId:'m001'}
```

コマンドの送信者は別の信頼できる通信層で認証され、`authorizedSeatId` の一致を確認する前提。JSON中の `actorId` が本人であるという保証だけではない。

**使うカードを選ぶ順序**は必須。習得済み〈壁〉は手札カードの選択列に続くものとして扱うため、〈虹のカーテン〉を先頭に置く順序を保てる。MP不足、未習得、関係ないカードとの複合防御を拒否する。
