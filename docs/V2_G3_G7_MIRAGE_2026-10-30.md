# V2 G3/G7｜〈蜃気楼〉・2〜6回の独立命中（2026-10-30）

## 実装範囲

**研究用ホットシートの1対1だけ**を対象に、原作資料と複数のプレイヤー報告に従って〈蜃気楼〉を共通攻撃コンパイラへ取り込んだ。今回の実装は新規の攻撃種類ごとの if (カード名) 分岐ではない。型付き `widenAttack({mode:'allLiving'})` と武器既存の `repeatAttack({count:2})` を合成する。

- 〈蜃気楼〉1枚：単体武器を全体対象化するが、研究用2人ルームでは防御するのは相手1人だけ。攻撃は**1回**。
- 〈蜃気楼〉2枚：**2回**の独立防御／命中。
- 〈蜃気楼〉3枚：**3回**の独立防御／命中。
- 〈のこぶんぶん〉の本来の2発に、蜃気楼2枚：**4発**、3枚：**6発**。後述の制約がある。
- 同じ武器・追加武器の攻撃力と元のターゲットは宣言時に固定し、各発で対象のHP・防御・反射・お守り判定をやり直す。**コスト・元の神器の消費は1度だけ、カード補充は最終命中の後**。
- 〈蜃気楼〉は攻撃を無属性化する。発火／魔水のワンドとの効果優先順は資料に言及があるが、現在のV2では複数特殊効果の組合せを正確に表現しきれていないので、**現状は一緒に使えない**。勝手に色を決めない。

## アーキテクチャ

- `src/verified-basic-cards.mjs` に `m012`〈蜃気楼〉（role=`wide_weapon`, MP5, ¥0, weight1）を追加し、部分研究表は **120種類・309/500参考枠**。全353種類・500参考枠は未達、正規ランダム抽選不可。
- `v2/foundation.mjs` は `onDeclare/widenAttack({mode:'allLiving'})` 以外を拒否。`v2/legacy-adapter.mjs` が厳格な Miracle データとして変換。
- `v2/ordered-attack.mjs` は蜃気楼を宣言された順で取り込み、`mirageCount`と`hitCount`を既存 `attackContext` に設定。`1×n`または`2×n`、nは1/2/3。多人数ルーム、ワンド・オーラ・火の玉等との未確認同時処理、吸収との同時処理を禁止。MP5×発動枚数。習得や手札補充は既存共通 interpreter。
- `v2/basic-resolution.mjs` は `strikeIndex` を `0..hitCount-1` の整数として各発の独立ダメージと防御を行い、`hitIndex+1<hitCount` のみ次へ。
- `v2/effect-runner.mjs` の `continueStrike` は初撃で攻撃神器を検証し、その後の cached context を不変比較し、各発の継続・復活・補充保留を扱う。元の実カードの存在を**消費前の状態**で確認。偽装の`hitCount`を拒否。
- `v2/redirect-resolution.mjs` は反射/弾き後の次発を元の相手に戻し、`v2/staging-room.mjs`／`v2/lab-ui.mjs` は安全な公開ビューの`strikeNumber/strikeCount`を使って「2/4発目」「3/4発目」「4/4発目」等を表示。
- `v2/demo/standalone.html`、旧`demo/standalone.html`を共に再生成。旧デモの新しい複数攻撃のゲーム挙動まで変更する意図はない。main/学校公開は未変更。

## 今回は対応しないもの（fail-closed）

1. **3人以上の〈蜃気楼〉全体攻撃**。原作の周回順や全体への反射、各プレイヤーの個別防御・HP0・全滅などを含む本物の全体ターゲティング基盤が必要。今回の2人実装をそのまま多人数へ流用しない。
2. **〈壁〉と蜃気楼/のこぶんぶん等の多段攻撃**。公開の「無属性武器を止める」は確認できるが、複数命中の1発だけを止めるのか、攻撃チェーン全体か、仕様を断定できないため引き続き拒否。原作クライアントか信頼できる複数資料で優先順位を確かめる。
3. **〈蜃気楼〉を発火／魔水ワンド・〈オーラ〉・その他奇跡と同時使用**。資料には複合技の説明があるが、現行コンパイラで再現の証拠が不足。
4. **習得済み〈蜃気楼〉を同一ターンに2度以上唱えること**は既存`getSelected`が同一の習得定義IDの再宣言を拒否するため未対応。ただし**物理カード1枚＋習得済み1回**を順に使い、2回攻撃になる組合せはNodeで実行・テスト済み。
5. 正規山札/無料オンライン、学校iPad Safari・Google Sites試験、全カード。**まだ公開版ではない**。
