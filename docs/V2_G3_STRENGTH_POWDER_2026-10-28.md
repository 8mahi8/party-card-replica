# G3｜ちからの粉の原作照合・カード定義追加（2026-10-28）

## 根拠

- **実際の原作APIを扱ったBOT研究者の報告（2025-10-05）**：https://note.com/oreapo_note/n/n7791e8e30943
  - 「力の粉」は`+攻`でも**武器ではない**ため、先頭で選ぶとサーバー拒否。
  - 「パンチ→力の粉→オーラ→精霊のぬいぐるみ」は**選択可能**な具体例。
  - 「パンチ→オーラ→力の粉→精霊のぬいぐるみ」は**精霊がオーラの直後でない**ため選択不可。
  - ただし、オーラと粉の同時使用で最終ダメージの**数値・乗算順位は記事にはない**。
- **2026-10-24更新のゴッドフィールドwiki（その他）**：https://w.atwiki.jp/piong/pages/19.html
  - `ちからの粉` は雑貨、`+攻10`、`¥15`、`0.4%`。
- **2026-02-28の個人神器一覧**：https://macarongamemo.com/entry/godfield-artifact
  - 同じ`+攻10`、売値`15`、`0.4%` を独立して確認。
- 追加武器単体が使える事実と**ちからの粉単体不可**という例外を混同しない。外部資料は直接サーバー実測ではなく、第三者の操作報告とデータ表。

## 変更（Draft PR #1 のみ）

- `src/verified-basic-cards.mjs`：`i004` を**item**の`support_item`として追加。攻撃力10、価格15、重み2（0.4%=500枠中2）。
- `v2/legacy-adapter.mjs`：`effect:'add_attack'`の非武器をカード個別名ではなく`onDeclare:addAttack`に翻訳。`playModes:['addAttack']`、`family:'item'`にするため、先頭に置いて攻撃はできない。
- `v2/ordered-attack.mjs`：武器のあとに選んだ攻撃補助itemは使用カードとして消費し、攻撃力を加算する。複数の粉や他のプラス奇跡とのダメージ優先順位は未確認につき引き続き拒否。
- **オーラ併用の拒否について**：公式が禁止すると言っているわけではない。むしろ研究記事は`パンチ→粉→オーラ→精霊`を**受理可能**と示す。開発版エンジンは**ダメージ計算が未調査のため一時的に未対応**としている。解決すべき優先度の高いG3残件。
- `v2/lab-controller.mjs`：エフェクトタグを読み、粉を「＋攻10」と表示。
- `tests/strength-powder-v2.test.mjs`：データ型、非武器単独不可、武器→粉のダメージ、MP0、カード消費と補充、原子性、未知順序の明示エラー、ホットシートUIのテスト追加。
- 旧参考カード数85種→**86種**、参考重み203枠→**205枠**。いずれも本家の完全な500枠デッキではない。原作確率を使う本番ランダム抽選は依然禁止。
