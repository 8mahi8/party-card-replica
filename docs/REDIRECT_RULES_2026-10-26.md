# 反射・弾く：資料と検証結果（2026-10-26）

## 原作資料（第三者公開情報）

1. [ゴッドフィールドwiki／単体武器](https://w.atwiki.jp/piong/pages/15.html)：乱弾武剣（攻5、￥10、1.4%／無属性武器を弾く）、反射剣（攻10、￥5、0.6%／無属性武器を跳ね返す）
2. [ゴッドフィールドwiki／防具](https://w.atwiki.jp/piong/pages/17.html)：スーパーミラー（￥10、0.2%／何でも跳ね返す）。「弾く」の対象は自分を含む生存者からランダム。自分に戻った攻撃は防具・反射を使って再防御できない
3. [God Fieldガイド＋α／神器一覧](https://w.atwiki.jp/gfplusa/pages/18.html)：跳ね返す・弾く・止めるの区別、奇跡攻撃の属性を取り除いても無属性武器限定反射は発動しない
4. [HIMATAMIの解説](https://himatami.jp/magazines/22)：タイマンの弾くは相手・自分に概ね50%ずつ。自己弾き戻りは防御できない

## 今回追加した3種類

- `w026`：乱弾武剣（通常武器、攻5、￥10、抽選枠7、neutral_weaponに対するdeflect）
- `w027`：反射剣（通常武器、攻10、￥5、抽選枠3、neutral_weaponに対するreflect）
- `i002`：スーパーミラー（防御用雑貨、￥10、抽選枠1、全属性reflect）

抽選枠は第三者資料上の500分母で、種類数は **57種類・合計174枠**。これは部分データであり、`createAuditedDraw` での本番抽選は禁止。

## 変更した処理

`src/match.mjs` の `defend(state, action, draw, rng)` にリダイレクト処理を追加。

1. 対象に選ばれた人が反射/弾くカードを**1枚だけ**選択（他の防御値カードとの効果順が確定していないため、同時選択は未サポート）
2. 反射剣・乱弾武剣の場合は無属性**武器**攻撃のみ対象。光・闇・火などの属性付き攻撃は不可
3. スーパーミラーは属性を問わず攻撃を元の攻撃者に返す
4. 弾くの抽選は生存者の集合から一様な乱数注入で決める。弾いたプレーヤー自身に戻ったときは追加防御なしで決着
5. 攻撃が別プレーヤーへ移ったときは、`pending.sourceId` を**現在の発射者**に更新。カード補充とターン順は**最初の攻撃者**を `originalAttackerId` として別に保持
6. 補充枚数は `spentByPlayer` に記録。反射で防御に参加した全員が消費した分を追跡し、解決時に生存者へ補充

イベントログには `redirect` イベントを保存する。リダイレクト中に終わったら、手番・勝者を同じ状態遷移で決定する。
