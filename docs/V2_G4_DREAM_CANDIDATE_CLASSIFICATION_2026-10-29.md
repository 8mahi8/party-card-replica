# V2 G4→G7｜夢の候補分類と原作例外の監査基盤（2026-10-29）

## 原作調査で確認したルール

2026年4月5日公開の[「夢状態における確率・期待値」](https://macarongamemo.com/entry/godfield-dream)（状態異常の補助資料：[ゴッドフィールドwiki・災い](https://w.atwiki.jp/piong/pages/23.html)）では、夢による神器の偽表示には次の重要条件がある。

- **授かった神器は50%の確率で別の神器に見える**。ランダム偽表示の母集団はプレイヤーの使用タイミングが一致するものだけ。たとえばエンゼルナイフを見た時点で、奇跡に反応できる＋攻ではない武器の候補に限定される。
- **奇跡と取引**、およびほかに同一使用タイミングを持たない特殊神器は夢の影響を受けない。掲載されている明確な例は「精霊の杖」「ほむら巻き」「魔神の木馬」「虹のカーテン」「スーパーミラー」「両替」「売る」「買う」「ちからの粉」「精霊のぬいぐるみ」「奇跡」。
- これまでの研究用`dreamTimingSignatureFixture`は、同じ使用タイミングであっても防御の**効果**（止める・弾く・はね返す）が違う場合に別署名になる、**原作より狭い安全側の近似**である。上の記事は「使用可能タイミング」の一致を要求しており、**防御結果の種類まで一致する必要があるとは断言していない**。
- 一方、上の原作例外をただのplayModesで分類すると、見た目を偽装できると**誤判定する**可能性がある。実際、現在の部分台帳には通常の攻守兼用武器と同じ近似署名の「ほむら巻き」があり、従来の署名だけでは判別しきれなかった。
- 複数の神器の本物率が約50%であることと、**候補ごとの抽選ウェイトを再現できることは別問題**。2026年の出現率一覧の全種類をエンジンの完全台帳に照合する必要があり、94種だけで抽選候補や確率を完成したことにはしない。

## 実装・今後のカード追加に使う仕組み

### `v2/dream-candidate-audit.mjs`（新設）

- `dreamSourceExclusionFixture(def)`：カード定義をIDで特定し、**原作の夢免疫例外**を構造化。今回の部分台帳で確認できた特例は`w020 ほむら巻き`、`i001 虹のカーテン`、`i002 スーパーミラー`、`i003 精霊のぬいぐるみ`、`i004 ちからの粉`。加えてfamily=`trade`または`miracle`を原作資料に基づいて必ず除外。**カード名の表示文字列をゲーム中の効果処理に利用しない**。
- `dreamLabTimingSignatureFixture(def)`：元の安全側署名を共有関数にして、見た目付与・検証・分類で同一ルールを使用。
- `dreamResearchClassificationFixture(def)`：`source-excluded`、`needs-rule-review`、`lab-classifiable`を区別。`i005 太陽のお守り`は原作の雑貨欄に本物率が載る一方、現在の受動カード実装は原作の夢候補を正確に表現できていないため`needs-rule-review`とした。**太陽のお守りが原作で絶対に偽表示にならない、とは主張しない**。
- `auditDreamResearchCatalogFixture(catalog)`：定義の追加に従って研究署名グループとカード一覧を**自動的に再分類**。同じ署名を持つ別カード個数、部分台帳の重み合計を算出するが、`complete:false,randomizationReady:false`を返す。部分台帳での署名が1枚しかなくても**原作で本当に夢免疫があるとは断定しない**。
- この監査は乱数を使わず、カード実体やプレイヤー状態を変更せず、結果の配列をfreeze。カタログの誤ったキーや不正なウェイトを拒否する。

### `v2/dream-appearance.mjs`（実行境界を強化）

- 2026年資料の免疫例外が**夢の見た目を付与する際・本人の手札を投影する際・内部の所有権をチェックする際のすべて**で拒否される。
- 「ほむら巻き」等の真の神器と、同じ安全側の使用タイミング署名を持つ別武器とを偽装する不正操作も拒否する。既に確立した研究用の普通の神器（本物：金のこん棒／偽表示：ワンダーソード）は引き続き使える。
- **新しいカードが増えても監査グループはコード変更なしで自動集計**。ただし新たに原作で判明した免疫例外は、出典確認を伴う明示的な定義を追加していく必要がある。

### 台帳のスナップショット（原作確率ではない）

| 指標 | 研究用部分台帳 |
| --- | ---: |
| 研究済みのカード定義 | **94種類** |
| 抽選ウェイトの参考枠 | **270枠** |
| 2026年資料に基づく除外・家族分類 | **19種類**（奇跡11・取引3・原作例外5） |
| 現状の受動タイミングでは原作に照らし保留 | **1種類**（太陽のお守り） |
| 安全側の研究用署名で分類するもの | **74種類** |

**270/500の残りを埋めるだけで正しい夢抽選になるわけではない。** 原作カードの全種類、ウェイト、例外、使用タイミングの知識が必須。これは分類の進捗であって**ゲーム完成率ではない**。

## 次の工程

原作の全カード定義の調査時に、カード1件ごとに**使用可能タイミング（通常攻撃、追加攻撃、通常防御、奇跡反応、受動、特殊行動）**と、特別な夢免疫例外の根拠を記録する。完全なカード表と原作の授かり率が揃うまでは、見た目の正規抽選を開始しない。
