# G4｜夢（旧名・幻覚）研究基盤：実神器と見た目の完全分離（2026-10-29）

## 結論・原作調査

2026年4月の比較的新しい攻略資料と2019〜2021年の名称変更記録を照合し、**旧称「幻覚」の状態異常は今の原作では「夢」**と判明した。以前のチャットで「幻覚解除」と呼んでいたものを、今後の正式な研究文書・UIでは「夢」に統一する。

| 内容 | 根拠 | 実装上の扱い |
| --- | --- | --- |
| 2019〜2021年頃に幻覚→夢へ名称変更 | [ゴッドフィールドwiki・トップの当時の掲示板記録](https://w.atwiki.jp/piong/) | 旧ルール名を使用しない |
| 夢では神器を授かる際約50%の確率で偽物に見える | [2026-04-05・まかろんの調査](https://macarongamemo.com/entry/godfield-dream)、[状態異常一覧](https://w.atwiki.jp/piong/pages/23.html) | **確率実装はまだしない** |
| 偽物の種類は同じ使用タイミングの神器から抽選。授かり率で重み付け | [2022年の制作者発言の転載・解説](https://note.com/rich_echium152/n/n02fdc4949096) | 全353種類／正規500枠が未完成。研究用94種だけを母集団として抽選すると偽確率になるので禁止 |
| 取引、奇跡、スーパーミラー等の固有タイミング神器は夢の影響外 | [2026年4月の仕様解説](https://macarongamemo.com/entry/godfield-dream) | 取引／奇跡／受動神器の見た目偽装を拒否 |
| 自分に「売る」と、売る対象にした神器の正体が明らかになり、カードは残る | [2015年実戦解説](https://ameblo.jp/godfield-tactics/entry-12100951333.html) | 非致死の自己売却のみ、選択した個体だけ見た目を確定 |
| 夢の治癒は所持神器の真偽を確定させる | [新しい災い一覧](https://w.atwiki.jp/piong/pages/23.html) | 治癒操作・新しいカード抽選は未実装 |

いずれも第三者資料または制作者発言の二次転載。**2026年10月現在の原作クライアントを直接操作・解析した証拠ではない**。本家の表示タイミングや全抽選分布を完成扱いしない。

## 新しいデータ構造

- `v2/dream-appearance.mjs` 新設。`attachDreamAppearanceFixture`で研究用の**明示的な偽の見た目**を指定。内部は`dreamDisguises:[{instanceId,appearsAsDefinitionId}]`。手札の`definitionId`は必ず本物のまま。状態変更はコピーし、原状態とRNGを変更しない。
- 真偽が違うだけでは不十分。**同じfamily、使用モード、攻守のタイミング、特殊防御、捨てられるか**の署名を厳密照合。現状の照合は安全性のため実際の候補より厳しく、原作の完全抽選ではない。
- `dreamVisibleDefinitionIdFixture`はその席が見るカード定義だけを返す。他席の実手札は公開しない。カタログがない場合は真の名前を漏らす代わりに拒否。
- `v2/staging-room.mjs`の`viewStagingRoom(state,viewerId,catalog)`から、**自席のカードは現在見える見た目**を投影。相手の手札・隠したデータ・RNG・原定義IDを公開しない。内部の本物の個体IDは変えない。
- `v2/effect-runner.mjs`で偽表示の配列を状態コピー時に深く複製。`selfSale`では売る対象の実個体のみ`dreamDisguises`から除外（ほかの幻惑表示を解除しない）。物理カードが`spend`や`discard`で手札を離れた場合は残留する表示データを除去。
- **夢の状態異常を与えるカードや50%抽選そのものは追加していない**。部分カード台帳94種／270参考枠を完全母集団の代わりに使うことはしない。

## 動作する研究シナリオ

- `v2/lab-controller.mjs`：`loadDreamTrial()`。P1は本物の`売る`・`金のこん棒（¥25）`・革の帽子を保持。**金のこん棒だけがワンダーソード（¥4）に見える**テスト状態。P2の手札は秘密。
- `v2/lab-ui.mjs`：「夢の神器を自分に売って確かめる」ボタンを追加。P1が見えているワンダーソードの個体を「売る」の対象として選ぶと、本物の金のこん棒の価格¥25で決済する。実体は残り、自己売却の消費のみ発生。次の手番に進み、見た目は実体に戻る。
- これは**原作の確率や全ての夢状態の再現ではなく、実体と見た目を分離するラボ実験**。実際の学校対戦・mainへは配布しない。

## テスト

- `tests/dream-appearance-v2.test.mjs`を13ケース新設：内部定義とRNGの保存、自席のみへの偽表示、カタログ欠如時の情報漏洩防止、商品実価格による決済と自己売却時の解除、取引/奇跡の偽装拒否、表示可能タイミング制約、データ破損の拒否、複数偽装カードの独立性、専用UIからの確認、物理instanceId保持。
- `tests/v2-webkit-smoke.browser.mjs`に**390×430固定iframeを実際にタップする夢研究シナリオ**を追加。偽の名前だけが見えること、自分への売却指定、実体の¥25に基づくMP5・¥25、相手の資源不変、秘密の手札移行を検証。
- `v2/demo/build.mjs`へ`v2/dream-appearance.mjs`を追加、`v2/demo/standalone.html`を**28モジュール**から再生成。

## 依然として残る原作照合

2. 自己売却で見た目が戻った後の、夢状態の継続と新しい神器に及ぶ処理。
3. 他人に売る・他人から買うでの真偽確定のタイミングと、鏡の反射への影響。
4. 致死売買・HP0・太陽のお守りが同じイベントに重なる場合の支払い・復活の優先順。
