# G4｜「売る」＋スーパーミラー（1回）の研究用決済シナリオ

2026-10-29｜開発ブランチ `refactor/v2-foundation-review-20261027`｜Draft PR #1

## 原作の出典：確定度を区別

1. [2025年7月・実プレイヤーのスーパーミラー攻略](https://kankurou53.hatenablog.com/entry/2025/07/19/165703)：スーパーミラーで「売る」を跳ね返せる。金のこん棒売却で返された側はステータスを25削られ、使った側は25円受け取る。「売る→売り返す→ミラー」の事例で50の資源差になることも記載。
2. [2025年6月・God Fieldレビュー](https://note.com/makariki/n/n437bc90ac4dc)：押し売りの金のこん棒が反射で元の売り手へ戻る。
3. [2021年攻略](https://ameblo.jp/shibransk/entry-12647363984.html)：取引「買う／売る」はスーパーミラー以外では防げない。売却益は金銭で受け取る。費用不足は所持金→MP→HP。
4. [原作の取引説明](https://w.atwiki.jp/aniwotawiki/pages/47010.html)：売るの `HP15 / MP10 / ¥5`・価格25の具体例。HP5/MP0/¥0になる。
5. [売るの手札補充の実体験](https://note.com/hixiragi/n/n47365b74f372)：売却された商品自身は補充されないが、消費した「売る」カードは補充される。

これらは独立の攻略・実践記録であり、**最新の原作クライアント/APIを直接操作した証拠ではない**。特に、スーパーミラーを何度も返す場合の途中の補充時点、受け渡しの瞬間、および売り手が死亡した場合の決済は未照合。研究用の1回反射だけに範囲を絞った。

## 実装したコード（対戦にまだ未接続）

- 新規 `v2/trade-reflection.mjs`
  - `previewSingleMirrorSale(state,catalog,selection,{mirrorInstanceId})` は純粋なプレビュー。現在の売り手が持っている本物の「売る」カード＋本物の商品＋**取引対象の手札にあるスーパーミラー**を確認。売り手は支払えること、反射側の受取額が安全整数であることも確認。
  - `settleSingleMirrorSaleFixture` は **`labOnly:true`かつ認証済みの元売り手**だけ実行可能。原価計算は既存 `v2/trade-payment.mjs`の純粋関数を再利用。
- `v2/effect-runner.mjs` の `reflectedSale` 効果：
  - 元の売り手（A）が買い手兼支払者となり、**元の商品の所有権はAに留まる**。
  - ミラーの使用者（B）が、元の商品の定義価格を**金銭で受け取る**。
  - 支払いは「Aの所持金→MP→HP」で支払う。
  - Aの「売る」カードとBの「スーパーミラー」を**それぞれ1枚ずつ使用し、各1枚だけ固定fixtureカードで補充**する。
  - 売り物は元のinstanceIdを保持。原カードをコピーしたり買い手へ移したりしない。
  - 処理キューに不正な `price:0` 等を混ぜたり、本物の取引カードとミラーを消費せず決済だけ強制する操作は拒否。失敗時、元のstateは不変。
- **対象死亡／支払いが不足／反射側の所持金オーバーフロー／次の反射**は今回の決済処理に入れない。原作資料未確認の挙動を「仮の実装」で上書きしない。
- **既存の通常の「売る」も含め、取引を `v2/staging-room.mjs` の一般コマンドや学校Google Sitesの対戦UIに接続していない。** いずれもLab研究用fixtureのみ。いわゆる「ゲームで売るが実際に遊べる状態」とは異なる。

## 新規テスト（`tests/mirror-sale-reaction-v2.test.mjs`）

10ケースを追加：
1. スーパーミラーの本物のカード効果と支払プランの検証。
2. 金のこん棒25円を反射すると、Aは元商品を持ち続け、Aの¥20→0・MP10→5、Bの¥20→45。売るカードとミラーそれぞれ1枚を消費・補充し、使用済みカードIDと商品個体IDを照合。
3. A=HP15/MP10/¥5→HP5/MP0/¥0、Bが25円受け取る。
4. 0円の奇跡売り付け返しはHP/MP/金銭不変、両アクションカードは消費される。
5. 反射がない取引と反射後の取引で、25円の支払い方向が逆転する。
6. 本物以外のミラー、持ち主の違うミラー、不正ターゲットは拒否。
7. 致死的反射／金銭オーバーフローは拒否、元状態不変。
8. 普通の反射剣は取引を返せず、スーパーミラーのみ有効。
9. 取引カード／ミラーを支払っていない偽処理、入力価格の偽装は拒否。
10. 通常対戦に偽装した呼び出しや同じ操作の二重実行を拒否。
