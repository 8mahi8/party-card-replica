# 学校カードゲーム｜原作ルール再現ラボ

学校iPad（Safari）で友達と遊ぶカード対戦ゲームを開発するための、**仕様調査・ルール検証プロジェクト**です。

**現在は戦闘ルールの検証用コードのみで、遊べるゲームではありません。**
実際の原作にないカード効果や数値を推測で追加せず、確認済みの項目から実装します。

## 状況（2026-10-26）

- [x] 初期ステータス HP40 / MP10 / 所持金20、初期手札9枚・上限18枚
- [x] 500枠のカテゴリ・属性別分布
- [x] 7属性（無属性を含む）の防御対応と基本ダメージ
- [x] 復元抽出と手札の基本補充
- [x] 奇跡の習得上限6個・MP消費
- [x] 反射／弾きの対象決定、押し売りの支払順
- [x] 上記基礎ルールの自動テスト10件
- [ ] カード353種類の効果・個別の重みを照合
- [ ] 一連のターン処理・例外判定
- [ ] BOT・対戦画面・オンライン同期
- [ ] Google Sitesのコード直接埋め込み用の単一HTML
- [ ] 原作挙動との突合・学校iPad実機確認

## テスト

Node.js 20以降、外部依存なし。

```sh
npm test
```

## 開発上の原則

- 独自のバランス調整・新規ルールを加えない。
- 著作物となる画像、ロゴ、固有の説明文をコピーしない。カード画像とUI素材は独自に用意する。
- 参考資料は公式仕様書ではない。公開資料から判明したことと、原作実機で確認したことを区別する。
- 未確認の挙動について、確認済みであると断定しない。
- 友達と学校のiPadで遊ぶための最終公開方法は**Google SitesへHTML/CSS/JSのコードを直接埋め込む方式**。GitHub PagesのURL埋め込みではない。

調査出典は [docs/SOURCE_LEDGER.md](docs/SOURCE_LEDGER.md)、作業順序は [docs/NEXT_STEPS.md](docs/NEXT_STEPS.md)。

**注：これは第三者のゲームを研究して作る独立した非公式プロジェクトであり、公式とは無関係です。**
