# 学校カードゲーム｜原作ルール再現ラボ

学校iPad（Safari）で友達と遊ぶため、ゴッドフィールドの**戦闘ルールの再現精度**を高める独立した検証プロジェクトです。

> **まだ試遊可能なゲームではありません。** カード全種、特殊効果、対戦UI、通信、BOT等は未完成。原作準拠を目指しますが、現行原作との一致を確認できたものだけを確定仕様として扱います。

## 技術的な構成

| ファイル | 役割 |
|---|---|
| `src/rules.mjs` | 属性・ダメージ・補充・抽選の基礎関数 |
| `src/match.mjs` | データのみの状態遷移。依存関数で乱数とカードを注入 |
| `tests/rules.test.mjs` | 基礎仕様の10テスト |
| `tests/match.test.mjs` | 攻撃・防御・ターン進行の12テスト |
| `src/catalog-audit.mjs` | 353種類・抽選500枠とカテゴリ別の整合性監査（2025年Wikiの表） |
| `tests/catalog-audit.test.mjs` | 完全性チェックと不一致検出の7テスト |
| `src/verified-basic-cards.mjs` | 35種類のカード情報（資料照合済みの部分サンプル） |
| `tests/verified-basic-cards.test.mjs` | 部分カード10件のテスト |
| `docs/CARD_RESEARCH_2026-10-26.md` | 出典と35種類の照合状況 |
| `docs/SCOPE_AND_SOURCES_2026-10-26.md` | 原作資料の版差、未確認点、実装の制限 |
| `docs/SOURCE_LEDGER.md` | 出典台帳 |
| `docs/NEXT_STEPS.md` | 開発順・引き継ぎ |

Node.js 20以上で、外部ライブラリなし。

```sh
npm test
```

GitHub Actionsでもpush/PR時にテストする設定です（実際のGitHub実行結果は別途確認）。

## 方針

- オリジナルの戦闘ルールやバランス調整を加えない。
- 参照ゲームの絵・ロゴ・説明文等は流用せず、独自の画像・表現にする。
- 第三者資料の数値は**更新時期と整合性**を記録して採用する。
- わからない特殊効果は擬似的に再現せず、未実装エラーとして扱う。
- 公開方法は**Google SitesへのHTML/CSS/JavaScriptコードの直接埋め込み**。URLの埋め込みではない。

非公式・非公認の独立プロジェクトです。公式サービスとは関係ありません。
